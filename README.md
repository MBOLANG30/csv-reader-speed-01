A faster drop-in replacement for make.fun's csv-reader 1.0.0 — a dependency-free ES module that reads broken CSV files (stray CRs, unterminated quotes, quote junk, short and long rows) and returns exactly what csv-reader returns, in a fraction of the CPU time. `solve.js` exports `run({text, header})` returning `{columns, rows, errors}`; it scans each field as a slice between native `indexOf` hits instead of walking the text a character at a time.

## Run it

```sh
MAKEFUN_INPUT_DIR=input MAKEFUN_OUTPUT_DIR=output node main.ts
```
